# 校园能力协议 (tjucli & Skills)

> “Unix 哲学：编写只做一件事并做好它的程序，编写程序以使其能够协同工作。”

天津大学校园内存在着数十个建设于不同年代、接口形式各异的教学与生活服务系统。如果让大模型直接用爬虫去解析 HTML 网页，不仅极易崩溃，还会产生大量不可控的幻觉。TJUClaw 的解法是：**将一切校园能力抽象为严格的 CLI 工具管道（`tjucli`）**。

---

## 独立工具库：tjucli

`tjucli` 是使用 Go 语言原生编写的高性能独立命令行工具，具备以下设计特征：

- **确定性的 JSON 契约**：无论底层是爬取静态页面还是调用校园接口，`tjucli` 的 stdout 输出始终是严格定义 Schema 的结构化 JSON；
- **自包含与无依赖**：编译后为单个极简二进制，可在任何沙箱容器中瞬间加载，内存开销极低；
- **退出码标准语义**：非零退出码精确对应参数错误、网络超时或鉴权失败，为 Agent 提供无可挑剔的反思（Reflection）线索。

```bash
# 示例：通过 tjucli 结构化检索线性代数课程公开资料
tjucli courses search --query "线性代数" --format json
```

## 领域技能规范：Skills

为了让智能体精准理解何时调用 `tjucli`、如何组织参数，系统定义了标准的 Skill 文档规范（如 `cli/skills/tjucli/SKILL.md`）：

- **渐进式意图披露**：只向模型暴露当前目标所需的子命令参数，不占用无谓的 Token 消耗；
- **结果真实性核验**：要求 Agent 在交付任何文件前，必须校验 `tjucli` 输出的 SHA-256 哈希与字节长度，严禁伪造下载状态。
