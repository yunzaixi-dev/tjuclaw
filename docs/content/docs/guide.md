# 产品使用指南

TJUClaw 当前提供账号登录、知识库、笔记、文件上传、智能体对话和知识库共享功能。Web 端入口是 [app.tjuclaw.cloud](https://app.tjuclaw.cloud)，文档站 `tjuclaw.cloud` 不承载登录。

## 1. 登录账号

1. 打开 [app.tjuclaw.cloud](https://app.tjuclaw.cloud)。
2. 输入邮箱，选择邮件验证码或密码登录。
3. 首次使用密码前，必须先完成邮箱验证；验证码只通过邮件发送。
4. 登录成功后会进入知识工作区。退出时使用左下角的“退出”。

如果没有收到验证码，请先检查垃圾邮件并确认邮箱地址无误，再重新发送。不要把验证码、密码或会话 Cookie 发给任何人。

## 2. 建立自己的知识库

首次登录会进入默认知识库。需要按课程、项目或社团分开整理时：

1. 打开左下角“设置”。
2. 在“新建知识库”中填写名称并创建。
3. 使用左上角下拉框切换知识库。
4. 只有自己拥有的知识库可以重命名、删除或发布；从市场接入的知识库是只读的。

建议一个长期主题对应一个知识库，例如“高等数学”“大创项目”“社团活动”。

## 3. 写笔记与上传资料

- 点击左侧“新建笔记”，填写标题和 Markdown 正文；编辑内容会保存到当前知识库。
- 选择一篇笔记后再新建，可以把新笔记放到它下面，形成层级目录。
- 使用左侧搜索框按标题和正文检索笔记。
- 点击“上传文件”把资料保存到当前知识库。请勿上传账号密码、验证码、身份证件等敏感材料。

当前知识库负责资料整理与共享；WeKnora 自动检索链路仍在接入，不要把“已上传”理解为智能体已经完成向量化或自动引用。

## 4. 使用智能体对话

1. 点击左侧“新建智能体”。
2. 如果输入框提示“先配置模型”，打开“设置”。
3. 有产品模型额度时可以直接使用；也可以填写自己的 OpenAI 兼容公网 HTTPS `Base URL`、`API Key` 和可选模型名。
4. 返回智能体页面输入问题，等待回答。

自带模型密钥只保存在服务端，不会写进笔记。请使用专用、可撤销、低权限的密钥。当前智能体执行、校园工具调用、隔离沙箱和知识库自动检索尚未完整接入；界面中的模型回答不代表这些动作已经实际执行。

## 5. 发布与接入知识库

- 在自己拥有的知识库中点击顶部“发布”，生成公开快照。
- 点击“市场”查看其他用户发布的知识库，并选择“接入”。
- 接入后的知识库只读；需要修改时请回到自己的知识库创建笔记。
- 发布者撤回快照后，市场条目会消失，已有接入也会在下次打开时失效。

发布前请逐篇检查内容。公开快照不应包含个人信息、课程平台凭据、未获授权的资料或第三方秘密。

## 6. 常见问题

### 页面提示未登录或会话失效

刷新页面后重新登录。Web 会话使用同源 HttpOnly Cookie；不要把 Cookie 复制到其他域名或当作 API Token 使用。

### 模型无法使用

检查设置中的剩余额度或自带模型配置。自带上游必须是公网 HTTPS 地址；保存后仍失败时，确认模型名、API Key 和上游兼容性。

### 上传后智能体没有引用资料

这是当前版本的能力边界：文件与笔记可以保存、检索和共享，但 WeKnora 检索以及完整 Agent 执行链路仍在接入。
