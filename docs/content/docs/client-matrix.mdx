# 客户端与全端同步

> “消除 Coding Agent 的形态孤岛，赋予智能体真正的全场景陪伴能力。”

传统 Coding Agent 往往局限于本地命令行（TUI）或单一 IDE 插件，而普通 AI 助手往往只是缺乏系统能力的纯网页。TJUClaw 采用现代化跨平台方案，构建了**全端一致、多设备无缝同步**的客户端矩阵。

---

## 客户端矩阵形态

| 平台形态 | 技术实现 | 适用场景 | 关键特性 |
| :--- | :--- | :--- | :--- |
| **Web 网页端** | React 19 + Vite + EdgeOne 边缘托管 | 任意公共电脑、图书馆浏览器 | 免安装、秒开直达、边缘全站加速 |
| **Windows 桌面端** | Tauri 2.0 (Rust) + NSIS 安装包 | 个人主力宿舍 PC / 笔记本 | 原生系统通知、快捷键、极低内存占用 |
| **Linux 桌面端** | Tauri 2.0 (Rust) + Debian `.deb` 包 | 开发者工作站 / 极客环境 | 原生 Wayland/X11 支持、与本地终端生态打通 |
| **Android 移动端** | Tauri Mobile (Rust + Android NDK) | 移动行走、课间自习室、随时查看 | 触控手势优化、锁屏/后台任务流式推送 |

---

## 多端会话与数据同步机制

### 1. 服务端权威会话流转
所有的任务创建、执行 Trace、中间草稿与产物文件由后端 API 统一仲裁，各客户端通过同源安全长连接/流式接口接收统一的状态流推送。

### 2. 跨端接力体验
- **宿舍下发，路上追踪**：在 PC 客户端下发一个下载多门专业课大作业资料的复杂任务；合上电脑出门后，打开手机 Android 客户端即可实时查看下载流与 SHA-256 校验进度；
- **偏好全端漫游**：智能体在某一端提炼出的学生个性化习惯（如常用的资料格式、所在学院专业），自动在全端所有客户端生效。

## 统一的设计系统（Design Tokens）

为了杜绝代码仓库中的审美分裂与组件重造，TJUClaw 全平台遵循严格的语义设计规范：
- **深色工坊质感**：基于沉稳的 `#0e1112` 底色，搭配科技北洋蓝（`#3388ff` / `#003366`）强调色；
- **共享 UI 库**：四端共享同一套 `src/components/ui/` 基础原子组件，保证各平台字体、间距、动画与交互行为 100% 对齐。
