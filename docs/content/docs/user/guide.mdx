# 使用指南

TJUClaw 的核心理念是：**“不仅给出文本回答，更交付可核验的真实结果”**。本指南介绍目标使用流程。校园 CLI 已支持公开课程资料查询与下载；下述 Pi 自动执行及工作空间交付流程仍待端到端验收，暂不作为已上线功能承诺。

## 典型场景：查找并下载课程资料

以“帮我找到这门课的复习资料，保存到我的工作空间”为例，整个使用链路如下：

### 1. 提交需求目标

在 Web 或桌面客户端的 Workspace 界面输入目标提示词：

> “请帮我检索《电路信号与系统》课程的相关资料，找到目录下的说明文件并保存到工作区。”

平台在创建任务时，会在后端生成一个唯一的 Task ID，并分配当前用户的独立工作目录空间。

### 2. 智能体规划与工具调用

智能体引擎（Pi）加载产品专用的 `tjucli` Skill，分步执行校园工具调用：

1. **检索课程**：
   ```bash
   tjucli course search "电路信号与系统" --json
   ```
   返回匹配到的课程目录路径 `/2020701_电路信号与系统` 及元数据。

2. **浏览目录**：
   ```bash
   tjucli course ls "/2020701_电路信号与系统" --json
   ```
   列出目录下可用文件及子目录，锁定目标文件 `README.md`。

3. **受控下载**：
   ```bash
   tjucli course download "/2020701_电路信号与系统/README.md" \
     --output "./course-readme.md" --json
   ```
   下载文件至当前受控沙箱目录，并计算文件实际大小与 SHA-256 校验和。

### 3. 检查交付物与溯源结果

执行完成后，客户端工作空间会展示完整的执行结果卡片：

- **文件状态**：`./course-readme.md`（文件真实存在且可下载/预览）
- **数据来源**：天津大学公开课程分享平台（`cs.tjuse.com`）
- **文件体积**：以实际下载结果为准
- **校验和（SHA-256）**：以实际下载文件计算结果为准
- **执行日志（Trace）**：展示完整的命令输入参数与执行退出码，确保每一步清晰可追溯。

## 异常与边界说明

- **未检索到匹配项**：智能体会如实反馈检索深度与未命中原因，不会臆造虚假课程名称或凭空生成不可靠的文件。
- **文件超过限额**：沙箱与下载协议默认限制单文件传输体积，超限文件会明确提示下载失败及限制原因。
- **涉及隐私鉴权**：公开资料无需登录，但个人成绩与课表等受限接口需要专门授权，智能体绝不越权尝试伪造会话。
