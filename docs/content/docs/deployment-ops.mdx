> “好的架构必须经受住真实网络环境、高并发访问与持续迭代的严酷考验。”

## 核心组件分层

### 1. EdgeOne 边缘网络层
- 托管静态 Web 客户端与 Next.js 文档站，实现全球毫秒级静态内容分发；
- 边缘防御恶意爬虫与 CC 攻击，保障校园服务高可用。

### 2. HAProxy 流量调度与安全收口
- 独立 HTTPS 回源通道，只开放受控端口，绝不对外暴露底层数据库或微服务端口；
- 负责同源 Cookie 保持、API 流量反向代理与 TLS 加密终结。

### 3. 全平台多端自动化持续集成 (CI/CD)
- **多平台并发编译**：每次版本发布自动触发 GitHub Actions / GitLab 流水线，并发构建 Web、Windows (`.exe`)、Linux (`.deb`)、Android (`.apk`)；
- **全自动化测试套件**：包含 Go 单元测试、Playwright 浏览器端到端冒烟测试与沙箱隔离检验，测试未通过严禁发布。
