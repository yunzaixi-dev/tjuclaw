# 长期记忆系统 (Memory System)

> “真正的智能体，绝不应该把每一个清晨都当成彼此的初次相识。”

传统大模型问答最令人沮丧的缺陷就是**“会话结束即失忆”**。学生每次咨询都要重复自己的专业、年级和偏好。TJUClaw 构建了分层的**渐进式长期记忆系统**。

---

## 记忆分层架构

TJUClaw 将智能体的认知模型划分为三层清晰的记忆架构：

```
+-----------------------------------------------------------------+
|                  1. 工作记忆 (Working Memory)                   |
|             当前会话的上下文窗口、动态多轮对话、即时指令           |
+-----------------------------------------------------------------+
                                  │
                          自动抽象与归纳提取
                                  ▼
+-----------------------------------------------------------------+
|                  2. 情境记忆 (Episodic Memory)                  |
|             执行过的历史重要任务、成功/失败的经验复盘             |
+-----------------------------------------------------------------+
                                  │
                          长期偏好与共性沉淀
                                  ▼
+-----------------------------------------------------------------+
|                  3. 核心画像记忆 (Profile Memory)               |
|         学生的学科专业、常用资料格式、常用自习校区、高频工具偏好    |
+-----------------------------------------------------------------+
```

---

## 混合检索与动态注机制

为了既能唤醒历史记忆，又绝不塞爆昂贵的上下文窗口（Context Window），TJUClaw 采用轻量混合检索：

- **关键词/标签快速过滤**：对学科代码（如“高等数学”、“微积分”）、校区名称等专有名词进行确定性索引匹配；
- **向量语义召回**：对自然语言意图进行语义关联，在毫秒级内检索出最相关的历史记忆片段；
- **动态预算注入**：根据任务类型自动截取最契合的 top-k 记忆段落，静默注入系统提示词（System Prompt），学生无需额外感知。

---

## 记忆的隐私与掌控权

- **完全属于学生**：所有提炼的记忆内容均对学生开放可视化查看；
- **随时编辑与遗忘**：学生可以在控制面板中一键修正对偏好的误判，或永久删除指定的敏感记忆记录。
