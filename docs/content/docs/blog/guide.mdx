# 使用场景与实操演示

本文档演示学生如何使用 TJUClaw 解决高频、繁琐的校园实际问题。

> **当前链路说明**：当前客户端与后端已打通任务创建、工作空间与状态持久化；Pi 智能体运行时与云端沙箱的受控执行管道仍在持续接入中。下文基于已验证的 tjucli 工具协议与产品执行模型展示目标链路。

## 智能体的思考与受控行动

以下为目标执行步骤。目前工作空间记录与 tjucli 工具可分别使用，智能体驱动沙箱完成整个流程仍在接入中：

```
+-----------------------------------------------------------+
| 1. 意图理解与规划                                           |
|    - 识别关键词：计算机学院、数据结构、期末复习课件           |
|    - 决定调用工具：tjucli courses search                  |
+-----------------------------------------------------------+
                              │
                              ▼
+-----------------------------------------------------------+
| 2. 执行确定性工具                                           |
|    $ tjucli courses search --query "数据结构" --format json |
+-----------------------------------------------------------+
                              │
                              ▼
+-----------------------------------------------------------+
| 3. 获取结构化结果与真实下载                                 |
|    - 匹配到公开平台历年课件包                               |
|    - 执行流式下载至沙箱工作目录                             |
+-----------------------------------------------------------+
                              │
                              ▼
+-----------------------------------------------------------+
| 4. 产物交付与文件验真                                       |
|    - 计算文件 SHA-256 哈希值与字节大小                      |
|    - 将合法产物挂载至学生工作空间，生成直链                 |
+-----------------------------------------------------------+
```

## 透明可追溯的 Trace 记录

在任务详情面板中，学生可以展开完整的执行 Trace：
- 调用的具体命令与入参；
- 执行耗时与退出码（`exit 0`）；
- 产物文件哈希：`e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855`。

杜绝不可验证的虚假链接，确保学生拿到的每一份课件都是真实可靠的文件产物。
