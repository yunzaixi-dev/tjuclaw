## 核心组件分层

### 1. EdgeOne 边缘网络层
- 托管静态 Web 客户端与 Next.js 文档站，实现全球毫秒级静态内容分发；
- 边缘防御恶意爬虫与 CC 攻击，保障校园服务高可用。

### 2. HAProxy / Nginx 流量调度与安全收口
- 独立 HTTPS 回源通道，只开放受控端口，绝不对外暴露底层数据库或内部微服务端口；
- 负责同源 Cookie 保持、API 流量反向代理剥离 `/api` 前缀与 TLS 加密终结；
- 将身份验证流量分流至 Ory Kratos 与 Cap PoW 验证服务，业务请求交由 Go API。

### 3. 内部服务隔离与安全四象限
- **认证中枢栈**：Ory Kratos + 自托管 Cap + 专用 PostgreSQL / Valkey，专注于邮箱验证码生成与人机防刷；
- **知识引擎栈**：WeKnora 独立 Compose 栈（Loopback UI `:18180` / App `:18181`），自带隔离数据库，专职文档解析与向量召回；
- **情报采集栈**：Bun Crawler 运行在专属容器中，拥有独立的 PostgreSQL，绝不与身份或业务库混用；
- **模型网关栈**：NewAPI 作为运维级模型路由代理，内部受控访问，隔离外网。

### 4. 全平台多端自动化持续集成 (CI/CD)
- **多平台并发编译**：每次版本发布自动触发 GitHub Actions / GitLab 流水线，并发构建 Web、Windows (`.exe`)、Linux (`.deb`)、Android (`.apk`)；
- **全自动化测试套件**：包含 Go 单元测试、Playwright 浏览器端到端冒烟测试、Docker 隔离环境下的真实 Kratos + Cap 认证链路测试，测试未通过严禁发布。
