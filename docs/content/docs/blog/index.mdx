# 技术博客与架构演进 (Engineering Blog)

TJUClaw 是一个面向真实校园场景的通用 Agent 系统，涵盖了前端跨端框架、网关层同源控制、沙箱运行时调度、长期记忆模型以及数据抓取引擎等多个子系统。

由于系统涉及的技术栈广、链路长，且处于持续的迭代演化之中，单一的宏观架构文档难以穷尽所有细节。因此，我们将系统开发过程中的技术决策、架构权衡与踩坑实践沉淀为一系列专题博客。

---

## 系列文章导航

### 1. 总体架构与系统边界

  - 核心内容：深入拆解 Client、API Gateway、Kratos 身份认证、WeKnora 知识引擎与沙箱执行环境之间的调用拓扑与职责划分。

### 2. 计算与存储的物理隔离
- **[《存算分离与存储架构演进》](/docs/blog/storage-compute)**

### 4. 记忆系统的工程落地
