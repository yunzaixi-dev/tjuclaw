## 开发环境

在仓库根目录运行 `task setup` 安装依赖，运行 `task docs:dev` 启动文档站。
`task dev` 启动产品客户端与 API，和文档站独立。
产品目录与文档站分开维护，尚未实现的功能不作为可用能力展示。

## 仓库协作

提交与版本规范见仓库根目录的 `CONTRIBUTING.md`。
提交前运行静态检查、类型检查和相关测试。

## 访问边界

本仓库按私有项目维护。文档站只收录经过审核的开发说明，
不收录内部计划、研究资料、账号凭据或实际部署配置。
