# 面向天津大学校园场景优化的通用智能体平台

**参赛选手：TJUClaw 项目团队**

## 参赛信息

- **参赛项目：** TJUClaw
- **参赛赛事：** 天津大学 AI 智能体大赛 2026
- **参赛方向：** 技术实现
- **项目定位：** 面向天津大学校园场景优化的通用智能体平台
- **项目主页：** [TJUClaw GitHub](https://github.com/yunzaixi-dev/tjuclaw)

## 产品能力

平台连接 Web、桌面与移动端入口、校园服务工具和云端智能体运行环境，支持课程资料查询、校园信息获取、文件交付与任务结果核验。

## 使用入口

在根目录运行 `task docs:dev` 启动本地产品说明站；从首页进入项目演示，可以直接查看完整产品流程。

项目文档持续围绕产品能力、使用方法、架构说明和参赛演示组织，便于校园用户与评审快速理解产品价值。
