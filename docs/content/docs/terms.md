账号注销后，我们将依据适用法律法规和《隐私政策》处理与该账号相关的数据。

由于备份、安全日志、法律规定保存期限以及分布式系统运行机制，部分数据可能无法立即从所有备份系统中物理删除。

在依法需要删除但暂时无法立即完成物理删除的情况下，我们将采取停止进一步处理及必要安全保护措施。
