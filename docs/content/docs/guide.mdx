# 使用场景与实操演示

本文档演示学生如何使用 TJUClaw 解决高频、繁琐的校园实际问题。

---

## 场景示例：专业课复习资料检索与校验

### 1. 学生提出自然语言需求

学生在客户端输入：
> “帮我找一下计算机学院《数据结构》期末复习课件，并下载到我的工作空间。”

---

## 智能体的思考与受控行动

智能体在隔离的沙箱环境中，经历以下确定性执行步骤：

```
+-----------------------------------------------------------+
| 1. 意图理解与规划                                           |
|    - 识别关键词：计算机学院、数据结构、期末复习课件           |
|    - 决定调用工具：tjucli courses search                  |
+-----------------------------------------------------------+
                              │
                              ▼
+-----------------------------------------------------------+
| 2. 执行确定性工具                                           |
|    $ tjucli courses search --query "数据结构" --format json |
+-----------------------------------------------------------+
                              │
                              ▼
+-----------------------------------------------------------+
| 3. 获取结构化结果与真实下载                                 |
|    - 匹配到公开平台历年课件包                               |
|    - 执行流式下载至沙箱工作目录                             |
+-----------------------------------------------------------+
                              │
                              ▼
+-----------------------------------------------------------+
| 4. 产物交付与文件验真                                       |
|    - 计算文件 SHA-256 哈希值与字节大小                      |
|    - 将合法产物挂载至学生工作空间，生成直链                 |
+-----------------------------------------------------------+
```

---

## 透明可追溯的 Trace 记录

在任务详情面板中，学生可以展开完整的执行 Trace：
- 调用的具体命令与入参；
- 执行耗时与退出码（`exit 0`）；
- 产物文件哈希：`e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855`。

杜绝不可验证的虚假链接，确保学生拿到的每一份课件都是真实可靠的文件产物。
