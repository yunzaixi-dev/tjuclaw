0.1.5 “远程开发”的第一块拼图：你连到账号的电脑，现在可以在 TJUClaw 里直接打开终端。

## 怎么用

1. 在电脑上更新 TJUClaw CLI，开放远程终端并保持连接：

   ```bash
   tjuclaw workspace allow terminal.open
   tjuclaw connect
   ```

   `workspace allow` 会替换整个许可列表，如果之前开放过其他能力（例如 `pi.prompt`），请一并写上。

2. 打开“工作”侧栏，在电脑那一行点终端按钮；或者在项目的菜单里选“在终端中打开”，shell 会直接在项目文件夹里启动。

## 你会看到

- 终端停靠在页面下方，可以拖动调整高度、收起，或开多个标签；一边和 Agent 对话一边看命令输出。
- 手机上终端占满屏幕，底部多一排 Esc、Tab、Ctrl 和方向键，弥补手机键盘缺的按键。
- 网络断开时会自动重连，输出不丢、不重复；进程退出时显示退出码。

## 安全与限制

- 只有电脑主人在本机开放了 `terminal.open` 才能打开终端，每次打开都会重新检查；撤销后新终端立即被拒绝。
- shell 只在 `workspace init` 选定的根目录内启动，但启动后拥有你本机账号的全部权限，请只在自己信任的电脑上开放。
- 电脑不需要开放任何入站端口：终端经 TJUClaw 服务器中转，服务器只在内存中保留最近 1 MB 输出，不写入磁盘。服务器更新时正在运行的终端会结束。
- 每台电脑最多同时开 4 个终端，闲置 30 分钟自动关闭。
- Windows 暂为简化模式：命令可以运行，但没有输入回显、行编辑和 vim 这类全屏程序。Linux 和 macOS 是完整的终端。
