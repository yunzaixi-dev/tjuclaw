## 命令行登录

运行 `tjuclaw login`，终端会显示一个链接和验证码；在已登录的浏览器里打开链接、核对验证码后点“允许”，CLI 就登录好了。

- 这个登录只能读写你的知识库：笔记、文件夹和文件。它不能查看模型密钥、MCP 设置和对话，也不能删除整个知识库。
- 在“设置 › 账户 › 命令行登录”里可以看到每台登录过的设备，随时吊销。登录一年后自动过期。
- 没有浏览器的服务器或自动化任务，可以把令牌放进环境变量 `TJUCLAW_TOKEN` 使用。

## 像 git 一样操作知识库

```bash
tjuclaw clone "课程笔记" notes
cd notes
# 用任何编辑器修改、新增、移动或删除文件
tjuclaw status
tjuclaw diff
tjuclaw push
```

- 文件夹是目录，笔记是 Markdown 文件，附件保持原样；新建的 `.md` 会成为笔记，其他文件会作为附件上传。
- `tjuclaw pull` 拉取在网页、手机或智能体里做的修改。
- 每次推送都会带上修改时所基于的版本：如果这期间别处改过同一条笔记，不会被覆盖，而是提示冲突；远端版本会保存在 `.tjuclaw/conflicts` 里，合并后运行 `tjuclaw resolve` 再推送。
- 删除文件夹时，只有它在知识库里也已经清空才会删除，不会误删只存在于网页上的内容。
- Claude Code、Codex 等其他 Agent 可以按 [技能说明](https://github.com/yunzaixi-dev/tjucli/blob/release/skills/tjuclaw-library/SKILL.md) 用同样的方式读写你的知识库。

## 表格

- 上传的 `.xlsx` 现在可以直接在线预览，按工作表切换，带行号和列标。
- 表格里的文字会被提取出来：搜索能找到，TJUClaw 的智能体也能读到表格内容。

## 已知限制

- 富文本笔记在本地显示为 Markdown，只能阅读；在本地修改它不会被推送。
- 表格预览显示公式的计算结果，不显示公式和格式；只预览前 1000 行、100 列。
- 单个文件最大 8 MB。
- CLI 需要更新到 0.1.2：运行 `tjuclaw update`。
