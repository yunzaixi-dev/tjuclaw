把电脑连到 TJUClaw、在网页和手机上打开它的终端，需要先装好 TJUClaw CLI（`tjuclaw`）。现在不用自己编译了，一条命令即可：

macOS 与 Linux：

```bash
curl -fsSL https://tjuclaw-release.zaixi.dev/cli/install.sh | sh
```

Windows，在 PowerShell 中：

```powershell
irm https://tjuclaw-release.zaixi.dev/cli/install.ps1 | iex
```

## 说明

- 支持 x64 与 arm64（包括 Apple 芯片的 Mac），共六个平台。
- 脚本会先用发布的 SHA256 校验下载内容，不一致就停止，不会替换已有文件。
- 默认装到 `~/.local/bin`；Windows 装到 `%LOCALAPPDATA%\Programs\tjuclaw` 并加入你的用户 PATH，不需要管理员权限。
- 再次运行同一条命令即可升级；可以用 `TJUCLAW_VERSION` 指定版本、`TJUCLAW_INSTALL_DIR` 指定目录。
- 下载由我们自己的下载站提供，国内访问不依赖 GitHub。
- 装好后运行 `tjuclaw workspace init` 和 `tjuclaw connect`，具体步骤见 [CLI 工作空间说明](https://github.com/yunzaixi-dev/tjucli/blob/release/WORKSPACES.md)。

## 已知限制

- Windows 上的远程终端仍是简化模式：命令可以运行，但没有输入回显、行编辑和全屏程序。
- 暂不支持 32 位系统。
