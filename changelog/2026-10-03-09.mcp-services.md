设置里新增了“MCP 服务”一栏。接入后，Agent 会在对话里按需调用这些服务的工具，每次调用都会显示在会话步骤里，标成“服务 · 工具”。

精选目录：首批有五个服务。DeepWiki 用来读懂 GitHub 上的开源项目，Context7 用来查编程库的最新文档，Exa 用来搜索网页和读取页面，这三个不填密钥也能用。高德地图可以搜索地点、规划路线和查天气，需要高德开放平台的 Web 服务 Key；GitHub 可以浏览仓库、管理 Issue 和 Pull Request，需要你自己的个人访问令牌，能做什么取决于令牌的权限。

自定义服务：也可以填写任何公网 HTTPS 的 MCP 地址（Streamable HTTP），并按服务要求选择不填密钥、Bearer 令牌、自定义请求头或 URL 参数。添加后可以随时检查连接、查看它提供的工具、暂停或移除。

密钥：保存在服务器上，只用于访问对应的服务，不会显示在浏览器里，也不会写进笔记或进入沙箱。

已知限制：还不支持需要 OAuth 登录的服务和旧版 SSE 端点；每个账号最多接入 12 个服务，每个服务最多提供 40 个工具。插件市场还在开发中。
