TJUClaw 升到 0.1。网页端已经是这个版本；桌面端会提示更新，安卓安装包需要重新下载；macOS 安装包暂不提供。

这一版主要包括：
- Agent 可以接入外部工具：在设置的“MCP 服务”里添加 DeepWiki、Context7、Exa 网页搜索、高德地图、GitHub，或任何公网的 MCP 地址。
- Agent 技能：在设置的“插件”里启用考前复习、实验报告、参考文献格式、文献精读、课程项目调试、英文写作润色，遇到相符的任务时 Agent 会先读取做法。
- 会话：回合进行中实时显示思考、工具调用和回复，修改笔记的步骤标出改了多少字；会话可以重命名和删除。
- 更流畅：整个界面都交给 React 编译器优化，状态变化时只重画用到它的部分；长会话里离屏幕远的消息不参与重绘。
- 打开网站直接是登录页；网页端和桌面端会自己发现新版本，并列出更新内容。
- 手机：笔记主页底部可以直接提问；键盘、返回键和搜索面板做了修正。

已知限制：
- 手机键盘弹出时的显示已在安卓 Chrome 上确认（浅色和深色）；iPhone 和添加到主屏幕的应用还需要更多确认，遇到问题欢迎反馈。
- 安卓安装包暂时没有应用内更新。
- 连接本机或云端完整系统环境的“系统工作空间”还没有开放。
