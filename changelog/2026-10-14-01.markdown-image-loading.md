description: 云端笔记正文中的图片支持直接从私有 R2 加载，并共用缓存与占位。

- **重复图片共用缓存**：同一附件在多处引用、切换笔记或切换编辑与阅读模式时，复用当前页面内的图片缓存，减少重复下载。附件版本变化后重新加载。
- **加载前先留出位置**：占位中显示图片说明与加载状态，图片就绪后显示原图。已知尺寸的图片按比例预留空间；窄幅图片使用简洁图标，适配手机和深浅色主题。
- **失败后直接重试**：网络或图片加载失败时，可以点击“重新加载”，无需修改笔记内容。
- **按阅读位置加载**：未缓存的图片接近可见区域时再加载，下载逻辑也延迟到首次取图时载入，减少笔记初次打开时的请求。
- **读取云端已有图片**：打开笔记时，先校验笔记归属，再通过 Forgejo 获取该工作空间中已有图片的下载地址，直接读取它原本使用的私有 R2 存储。相对路径、Obsidian 图片引用和正文中的 HTML 图片共用占位和缓存；云端仓库中的图片也不再要求先有旧版文件条目。图片不需要复制或重新上传，也不新增存储桶。

附件缓存仅保留在当前页面的内存中，有容量和有效期限制；刷新页面、退出或切换账号后清空，不提供离线图片保存。外部图片沿用浏览器缓存。首次加载且未标注尺寸的图片使用默认比例占位，读取实际尺寸后仍可能调整高度。

直读需要现有 Forgejo 开启 LFS 对象存储直读，并允许网页跨域访问已有 R2 存储。下载地址使用 Forgejo 的有效期，目前为五分钟；地址失效或网页策略阻止直读时自动尝试鉴权后的图片接口。普通 Git 图片、原生客户端以及旧版附件仍可通过接口读取。订阅副本沿用原有不可变附件，不访问私人工作空间。删除笔记或图片后停止签发新地址，先前签发的地址可能在剩余有效期内使用。

本改动尚未发布。
