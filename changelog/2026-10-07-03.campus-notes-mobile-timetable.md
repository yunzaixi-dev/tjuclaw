- **手机可以直接看整周**：参考微北洋的七列布局，日期与课程同时适应屏幕宽度，不再需要左右滚动；上午、下午和晚间分段展示。点击课程可查看完整课程名、教室和已提供的教师信息，重叠安排也保留入口。
- **校园工具也是笔记入口**：课程表与入校码显示在资料库的笔记分区，可以像笔记一样打开或移除，并从「设置 → 校园账号」恢复。删除只移除入口，不清除账号或手动课表。入口状态按账号和资料库保存在当前设备，暂不跨设备同步。
- **办公网验证使用正确协议**：改用微北洋公开客户端采用的教务查询服务，不再把办公网单点登录网页当成提供验证码和 JSON 教务数据的接口。验证不会自动保存账号，也不会替换当前工具连接；教务服务异常仍明确表示无法判断密码是否正确。
- **如实说明请求路径**：网页端不是设备直连校园网站；查询经本站 API 转发至微北洋教务服务。校园密码仍以独立口令加密保存在本机，使用时在内存中解锁并随请求发送，本站服务端不持久化密码，只短暂保留本次教务结果。未接入 Agent 密钥管理。

本次发布网页端与 PWA，不发布新的原生安装包。回归使用合成校园账号与服务，不能代替真实校园账号实测；上游校园服务的网络与维护状态仍可能影响验证和数据获取。
